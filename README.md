# Controller Overlay
> A Controller overlay to shows controller inputs where it's possible to add a web source. I use it in OBS as a _'OBS Widget'_.

This is a controller overlay that I've created to learn more about vanilla JS and to use my _"own customizable controller overlay"_ in OBS _(Open Broadcaster Software)_. It currently shows activity of every button, bumper, trigger and analog-sticks that the [Gamepad API](https://developer.mozilla.org/en-US/docs/Web/API/Gamepad_API) supports.This was made with only vanilla JS and a small brain, there is no AI involved _(as you can see by the great code)_.

## How to customize it
You can create a controller image following the `assets` directory structure, where you have a `controller-skull.png` with no buttons _(or with base ones)_ and sub-directories for every other part.
